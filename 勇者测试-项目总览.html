🧱 技术架构

浏览器 ──> Nginx (前端 :80) ──> SpringBoot (:8080) ──┬──> MySQL 8   (25 张表 : 13306)
                                                    ├──> Redis     (排行榜/分布式锁 : 16379)
                                                    └──> MinIO     (签名 URL 防盗链 : 9000/9001)

GitHub Actions CI ──> mvn test + package / npm build ──> docker compose 一键部署
并发安全设计：接单 = Redis SETNX 锁 + DB 条件更新双保险防超抢；扣款 = UPDATE ... WHERE balance >= ? 乐观防超支；月度结算 = 幂等键防重复。
